# Orion Field Photography & Asset Directory

Welcome to the photo archive for the Orion website!

This folder is the designated home for all authentic, high-resolution photographs taken during Orion Fiatalok Informális Csoportja's Erasmus+ youth mobilities, community workshops, and leadership activities.

## Quick Rules for Adding Photos

1. **Aspect Ratio & Dimensions**:
   - **Project gallery photos**: Landscape `3:2` or `16:10` (recommended: **`1800 × 1200 px`**).
   - **Team member portraits**: Square `1:1` (recommended: **`800 × 800 px`**).
2. **File Size**:
   - Keep images under **350 KB** each so the website loads instantly on mobile connections.
   - Use free online compression tools like [Squoosh.app](https://squoosh.app) or [TinyJPG](https://tinyjpg.com) before uploading.
3. **Format**:
   - Standard `.jpg`, `.jpeg`, or `.webp`.
4. **Naming**:
   - Use lowercase letters, numbers, and hyphens only (e.g. `reforest-planting-01.jpg`). Avoid spaces and special characters.
